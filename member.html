Research — paste a URL to research

Give a page to research and its facts become context in the prompt. A static page cannot fetch an arbitrary URL from your browser (the site's own rules block it — CORS), so the backend fetches it server-side. If no backend is configured, paste the page's title and description yourself below.

Honest note: an image is only generated when you have linked your own image API key (link it in Connect AI on the Builder page — OpenAI image generation is supported from the browser). Without a key, no image is generated or faked: you get the prompt ready to copy, plus links to open it in ChatGPT / DALL·E, Gemini or Adobe Firefly, so you can check the result there. Gemini and Claude do not offer a direct browser image call from a static site, so with those linked the page says so and gives you the links instead. Reference files are previewed locally only — they are never uploaded to any server. Research URLs are fetched by the optional backend (see backend/README.md); without it, use the title and description fields above.
