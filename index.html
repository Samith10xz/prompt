(10) Connect AI — optional, your own key

The studio works fully offline with its built-in detailed generator — no key needed. If you link your own AI key, Generate can also ask that provider to refine the prompt. Your key is stored only in this browser (localStorage), is never sent to Graphix or to any server we run, and is only sent by your browser directly to the provider you choose.

Backend — Gemini & Claude, keys on the server (v1.2)

The optional backend in backend/ holds your Gemini and Claude keys on the server — the browser never sees them. That is also the only way Claude works at all: its API does not allow direct browser calls. When a backend URL is set here, Generate tries it first; if it is not set (or has no key), the studio falls back to your browser key, then to the built-in generator — and says so.

No backend yet? See backend/README.md for how to deploy it (Hostinger VPS or any Node host) and what it needs. No real API key is needed for the site to work — the built-in generator is always there.

Honest note: live AI calls from your browser depend on the provider allowing browser calls. Gemini keys usually work directly. OpenAI keys often work, but may be blocked by the provider's browser rules. Claude's API does not allow direct browser calls (it needs the backend in between), so with Claude linked only in the browser the studio will tell you that and keep using the built-in generator — it will not pretend the call worked. Without any key, everything still works: the built-in generator produces the full detailed prompt below.
